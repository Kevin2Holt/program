## What the main app is

`progr.am` is a server-rendered web application for creating and viewing event programs and itineraries.

Important architectural truths that must remain intact:
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Framework: Express
- Templating: EJS
- Database: PostgreSQL
- Public route model is code-first
- Main public event route shape is `/:code`
- The calendar module is intended to live under `/:code/calendar`
- Dark mode is default
- Light mode is available
- The app uses server-rendered pages, not a SPA architecture
- The app uses an established folder structure with routes/controllers/models/services/views/public assets
- Merge compatibility with the main codebase is a core requirement

---

## What the calendar module is

The calendar module is a merge-ready event submodule for:
- date-based signups
- optional time-based signups
- missionary meal calendars
- meal trains
- breakout sessions
- seminar/session registration
- RSVP-like capacity tracking
- similar event scheduling use cases

It must support:
- organizer-defined Items
- capacity
- availability and unavailability rules
- date windows
- optional timeslots / occurrences
- multi-item selection
- multi-day selection
- organizer editing and rescheduling
- organizer export
- permission-aware organizer access
- a public user flow and organizer management flow
